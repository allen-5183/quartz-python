## Q&A

### 1. VS Code's MCP 伺服器已停用

1. `VS Code` 上 開啟「檢視 → 輸出」，選 `GitHub Copilot Chat`，找這句 policy 訊息
   ![[assets/2. GitHub Copilot/IMG-20260805201748903.png]]
2. `VS Code`使用`GitHub Copilot Chat`的`MCP Servers 功能時，介面顯示「MCP 伺服器已停用」與「您的組織已停用對 MCP 伺服器的存取」。我已確認本機 [mcp.json](vscode-file://vscode-app/c:/Program%20Files/Microsoft%20VS%20Code/1b6a188127/resources/app/out/vs/code/electron-browser/workbench/workbench.html) 設定正常，資料庫參數也已填寫；Copilot Chat 日誌中明確出現：  
   Copilot preview features are disabled by organizational policy.  
   目前帳號授權類型顯示為 Copilot Business，因此推測是組織層級政策關閉了 Copilot 的預覽功能，連帶使 MCP Servers 無法使用。請協助確認並開啟 GitHub Copilot 組織設定中的 preview features / MCP 相關功能。參考說明：  
   [https://aka.ms/github-copilot-org-enable-features](vscode-file://vscode-app/c:/Program%20Files/Microsoft%20VS%20Code/1b6a188127/resources/app/out/vs/code/electron-browser/workbench/workbench.html)
