`Python`語言的編譯器提供一個已定義好的函式集合稱為「標準函式庫」，在標準函式庫裡有輸出入函式、數值函式、字串函式、檔案輸出入函式、時間函式、亂數函式…等。

### 1. 數值函式

| 函式 | 使用說明 |
| --- | --- |
| `abs(n)` | 取得 n 的絕對值。<br>例：`num = abs(-8)` `# num ← 8` |
| `round(n)` | 取得 n 四捨六入後的整數值。當小數第一位數字是 5 時，若前一位數字是偶數則捨去；若前一位數字是奇數則進位。<br>例：`num = round(12.6)` `# num ← 13`<br>例：`num = round(12.4)` `# num ← 12`<br>例：`num = round(12.5)` `# num ← 12, 因 2 是偶數`<br>例：`num = round(11.5)` `# num ← 12, 因 1 是奇數` |
| `int(n)` | 將 n 轉換成整數(小數部分直接捨去)。<br>例：`num = int(12.35)` `# num ← 12` |
| `float(n)` | 將 n 轉換成浮點數。<br>例：`num = float(12)` `# num ← 12.0` |
| `hex(n)` | 將 n 轉換成十六進位數字。<br>例：`num = hex(254)` `# num ← 0xfe` |
| `oct(n)` | 將 n 轉換成八進位數字。<br>例：`num = oct(12)` `# num ← 0o14` |
| `divmod(n, m)` | 取得 n 除以 m 的商和餘數。<br>例：`(x, y) = divmod(23, 5)` `# x ← 4, y ← 3`<br>例：`ret = divmod(23, 5)` `# ret[0] ← 4, ret[1] ← 3` |
| `pow(n, m)` | 取得 n 的 m 次方。<br>例：`num = pow(5, 3)` `# num ← 125` |
| `chr(n)` | 取得 Unicode 編碼 n 的字元。<br>例：`s = chr(20013)` `# s ← '中'` |
| `ord(s)` | 取得 s 字元的 Unicode 編碼值。<br>例：`n = ord('中')` `# n ← 20013` |

1. `abs(n)` 取得絕對值
   常用於計算距離、溫差或誤差值（避免出現負數）。   
   [案例]： 計算兩地溫差。 檔案: `abs.py`    
   > [!example]- 程式碼: `abs.py`
   > ```python
   > temp_a = 15  # 城市 A 溫度
   > temp_b = -3  # 城市 B 溫度
   >
   > temp_diff = abs(temp_a - temp_b)
   > print(f"兩地溫差為 {temp_diff} 度")  # 輸出：兩地溫差為 18 度
   > ```
   
2. `round() 函式` 奇進偶捨（Banker's Rounding）
   `round()`函式是以 **「四捨六入五成雙」** 的方式將浮點數轉換成整數值,但也可以指定要轉換的小數位數,使轉換成小數位數較小的浮點數，用於財務或統計計算，避免大量數據進位時產生累積偏誤

    語法如下:

     ```python
     round(n, m)
     ```

	> [!example]- 程式碼: `round.py`
	> ```python
	> scores = [12.5, 11.5, 13.5, 14.5, 14.51]
	> rounded_scores = [round(score) for score in scores]
	> # 沒指定 m 小數位數時
	> # Python 使用的是「四捨六入五成雙」（Banker's Rounding / 銀行家捨入法）。當遇到小數點後剛好是 .5 時，會取向最近的偶數
	> # 「五成雙」只適用於**剛好等於 5** 的情況
    > # 12.5  -> 12 (前位 2 為偶數，捨去)
    > # 11.5  -> 12 (前位 1 為奇數，進位)
    > # 13.5  -> 14 (前位 3 為奇數，進位)
    > # 14.5  -> 14 (前位 4 為偶數，捨去)
    > #「五成雙」只適用於剛好等於 5 的情況。如果 5 的後面還有數字（例如 14.51），這在數學上整體大於 0.5，就會直接歸類到「大於 5 ➔ 進位」的規則，變成 3
	> # 14.51 -> 15
	> print(rounded_scores)  # 輸出：[12, 12, 14, 14, 15]
	> 
	> # 指定 m 小數位數時，也是採用「四捨六入五成雙」
    > num=round(12.365,1) # num 12.4   保留 1 小數，觀察 6, 6 > 5 進位。這屬於「六入」。
    > num=round(12.367,2) # num 12.37  保留 2 小數，觀察 7, 7 > 5 進位。這屬於「六入」。
    > num=round(12.364,2) # num 12.36  保留 2 小數，觀察 4, 4 < 5 捨去位。這屬於「四捨」。
    > 
    > # 若遇到剛好要捨入的位數是 5，一樣會遵循偶數優先規則：
    > # 保留 2 位小數，看第 3 位 (5) 
    > print(round(12.325, 2)) # 輸出 12.32 (前一位 2 是偶數 -> 捨去)
    > print(round(12.335, 2)) # 輸出 12.34 (前一位 3 是奇數 -> 進位)
	> ```

	**說明**
    1. 參數`n`是用來被轉換的浮點數,參數`m`是指定轉換結果的小數位數。
    2. 參數`m`省略,則預設的轉換結果為整數。
    3. 不論有沒有指定小數位數，Python 的 `round()` **全都是採用「四捨六入五成雙」**
     
4. `int(n)` 轉為整數（直接捨去小數） 檔案: `int.py`
    常用於只取整數部分的場景，例如計算完整幾年、幾天。
	>  [案例]： 計算使用者滿幾歲（不考慮未滿一歲的小數）

	> [!example]- 程式碼: `int.py`
	> ```python
    > exact_age = 25.85
    > 
    > age = int(exact_age)
    > print(f"使用者今年滿 {age} 歲")  # 輸出：使用者今年滿 25 歲
	> ```
    
5. `float(n)` 轉為浮點數
    常用於處理使用者輸入或計算精確金額。
   	[案例]： 將輸入的字串數字轉為浮點數進行價格計算。 檔案: `float.py`
    > [!example]- 程式碼: `float.py`
    > ```python
    > price_input = "199"
    > discount = 0.85
    > 
    > final_price = float(price_input) * discount
    > print(f"打折後價格：{final_price}")  # 輸出：打折後價格：169.15
    > ```

6. `hex(n)` 與 `oct(n)` 進位制轉換
    常用於色碼轉換、系統權限或硬體底層通訊。
    [案例1]： 將` RGB` 色碼（`0~255`）轉為十六進位網頁色碼。 檔案: `hex.py`
    > [!example]- 程式碼: `hex.py`
    > ```python
    > r, g, b = 255, 165, 0 # 橘色 
    > hex_color = f"#{hex(r)[2:]}{hex(g)[2:]}{hex(b)[2:]}"
    > # # 0xff 0xa5 0x0  ff a5 0  #ffa50
    > print(hex_color) # 輸出：#ffa50
    > ```
    
    [案例2]： 查看 `Linux` 檔案權限的八進位表示。  檔案 : `oct.py`
    > [!example]- 程式碼: `oct.py`
    > ```python
    > chmod_val = 493 # 對應 rwxr-xr-x 
    > print(oct(chmod_val)) # 輸出：0o755
    > ```

7. `divmod(n, m)` 同時取得商數與餘數
    常用於時間轉換（秒轉分秒）、分頁計算（計算總頁數與最後一頁剩餘數量）。

    [案例]： 將總秒數轉為「幾分幾秒」。 檔案: `divmov1.py`
    > [!example]- 程式碼: `divmov1.py`
    > ```python
	> total_seconds = 385
    > minutes, seconds = divmod(total_seconds, 60)
    > print(f"總共是 {minutes} 分 {seconds} 秒")  
    > # 總共是 6 分 25 秒
    > ```

    [案例]： 學年結束,老師將剩餘班費`6359`元,平均歸給學生`28`人,則每位學生可分到多少錢,仍剩多少元。   (檔名:`divmod2.py`)

    [結果]

     ```yaml
     班費剩餘 6359 元, 學生有 28 人
     每人均分得 227 元
     班費仍剩餘 3 元
     ```

    [程式碼]
    > [!example]- 程式碼: `divmod2.py` 
    > ```python
    > money = 6359
    > person = 28
    > print(f'班費剩餘 {money} 元, 學生有 {person} 人')
    > (div, mod) = divmod(money, person)
    > print (f'每人均分得 {div} 元')
    > print (f'班費仍剩餘 {mod} 元')
    > ````

8. `pow()`函式  次方計算
    常用於複利計算、幾何面積/體積計算或密碼學。 語法如下:

    ```python
    pow(n, m, k)
    ```

	**說明**
    三個參數的運算意義是,`n`的`m`次方結果再除以`k`的餘數。
    例:`print(mod:=pow(4,3,10))` # `(4 ** 3) % 10 = 4`
    例:`print(mod:=pow(10,2,9))` # `(10 ** 2) % 9 = 1`

    [案例]： 計算本利和（本金 10000 元，年利率 5%，存 3 年）
    > [!example]- 程式碼: `pow.py` 
    > principal = 10000
    > rate = 1.05
    > years = 3
    >
    > total = principal * pow(rate, years)
    > print(f"3 年後本利和：{round(total)} 元")  # 輸出：3 年後本利和：11576 元 
	>```

9. `chr(n)` 與 `ord(s)` Unicode 字元與編碼對轉換
   常用於加密解密（如凱撒密碼）、產生連續英文字母選單、或判斷字元範圍。
   - **`ord(s)`**：輸入**單一字元**，傳回其對應的 **Unicode 編碼數字**。
   - **`chr(n)`**：輸入 **Unicode 編碼數字**，傳回其對應的 **字元**。
   [案例]： 將字元轉為 ASCII / Unicode 數字。 檔案: `ord.py`
   > [!example]- 程式碼: `ord.py`
   > ```python
   > # 基本英文字母與數字
   > print(ord('A'))  # 輸出: 65
   > print(ord('a'))  # 輸出: 97
   > print(ord('0'))  # 輸出: 48
   >
   > # 中文字元與 Emoji 
   > print(ord('台')) # 輸出: 21488 
   > print(ord('😊')) # 輸出: 128522
   > ```
   
   [案例]： 將 Unicode 數字轉回字元。 檔案: `char.py`
   > [!example]- 程式碼: `char.py`
   > ```python
   > # 基本 ASCII 轉字元
   > print(chr(65))   # 輸出: 'A'
   > print(chr(97))   # 輸出: 'a'
   > print(chr(48))   # 輸出: '0'
   > 
   > # Unicode 轉中文與 Emoji
   > print(chr(21488))  # 輸出: '台'
   > print(chr(128522)) # 輸出: '😊'
   >  
   > # 快速產生 A ~ Z 英文字母清單
   > # ASCII 中 A 是 65，Z 是 90
   > alphabet = [chr(i) for i in range(65, 91)]
   > print(alphabet)
   > # ['A', 'B', 'C', ..., 'Z']
   > 
   > # 簡單的字母位移（凱撒密碼原理）
   > # 利用 `ord()` 算出數字後加減，再用 `chr()` 轉回字元：
   > char = 'C'
   > shift = 3
   > # 將 'C' 向後推 3 個字母
   > new_char = chr(ord(char) + shift)
   > print(f"'{char}' 向後推 {shift} 位是: '{new_char}'")
   > # 輸出: 'C' 向後推 3 位是: 'F'
   > ```    

### 2. math 套件函式

數值的內建函式不止上一小節那些函式，還有定義在 `math` 套件中的數值函式，如： `sin()`、`exp()`、log()…。不過要使用套件內的函式，必須在使用前匯入套件名稱，匯入套件的敘述如下：

```python
import 套件名稱
```

[例] 匯入`math` 套件名稱

```python
import math
```

[例] 給一套件別名
套件名稱在匯入時，可以另外取較簡短或有特殊意義的別名，例如將 math 套件另外取別名為`M`，其匯入敘述如下：

```python
import math as M
```

1. 幾何與面積計算（`pi`,`sqrt`,`pow`）
   常用於計算圓形面積、球體體積或畢氏定理（直角三角形斜邊長）。
   [案例]： 計算圓形面積與斜邊長。 檔案: `pi.py`
   > [!example]- 程式碼: `pi.py`
   > ```python
   > import math
   > # 案例：計算圓形面積與斜邊長
   > radius = 5.0
   > circle_area = math.pi * (radius ** 2)
   > print(f"半徑 {radius} 的圓面積：{circle_area:.2f}")  # 輸出：78.54
   > # 畢氏定理：計算直角三角形斜邊 (a=3, b=4)
   > a, b = 3.0, 4.0
   > c = math.sqrt(a**2 + b**2)
   > print(f"斜邊長 c：{c}")  # 輸出：5.0
   > ```

2. 無條件進位與捨去（`ceil`,`floor`）
   常用於物流箱數計算、租車天數或遊戲天數計算。
   [案例]： 計算商品包裝箱數（每箱裝 10 件，共有 23 件商品）。 檔案: `ceil.py`
   > [!example]- 程式碼: `ceil.py`
   > ```python
   > import math
   > items = 23 
   > capacity_per_box = 10 
   > boxes_needed = math.ceil(items / capacity_per_box) 
   > print(f"需要箱數：{boxes_needed}") 
   > # 需要箱數：3       (無條件進位)
   > ```

   [案例]： 計算完整租借天數（滿 24 小時算一天）。 檔案: `floor.py`
   > [!example]- 程式碼: `floor.py`
   > ```python
   > import math
   > rent_hours = 50 
   > days = math.floor(rent_hours / 24) 
   > print(f"滿天數：{days} 天") 
   > # 滿天數：2 天 (無條件捨去)
   > ```

3. 指數與對數（`exp`,`log`,`e`）
   常用於計算複利、資料規模成長或自然科學演算法（如衰減率）。
   - ** $e$（歐拉數）**：是一個數學常數，數值約等於 `2.71828`。
   - ** exp(x) 的含義**：代表計算 $e$ 的 $x$ 次方（即 $e^x$）。
   - 
   [案例1]： 計算資訊學中的位元數需求 (以`2`為底的對數)
   > [!example]- 程式碼 log.py
   > ```python
   > import math
   > print(f"圓周率 π：{math.pi}") # 輸出：3.141592653589793
   > print(f"自然對數 e：{math.e}") # 輸出：2.718281828459045
   > # 欲儲存 1000 種狀態，至少需要多少個位元 (Bits)？
   > states = 1000
   > # 計算公式：ceil(log2(states))，其中 log2 為以 2 為底的對數
   > bits_needed = math.ceil(math.log(states, 2))
   > print(f"儲存 {states} 種狀態需要 {bits_needed} 個位元")
   > # 儲存 1000 種狀態需要 10 個位元
   > ```

   [案例2]： 計算連續複利（公式：P \* e^(r*t)））
   > [!example]- 程式碼 exp.py
   > ```python
   > import math
   > principal = 10000 # 本金 10,000
   > rate = 0.05 # 年利率 5%
   > years = 3 # 3 年
   > # 計算連續複利公式：A = P * e^(r*t)
   > amount = principal * math.exp(rate * years)
   > print(f"連續複利後的總金額：{amount:.2f}")
   > # 連續複利後的總金額：11618.34
   > ```

5. 三角函數與反三角函數（`sin`, `cos`, `tan`, `asin`, `acos`, `atan`）
   常用於遊戲開發（角度計算、物體移動軌跡）、建築測量與物理模擬。
   > **注意事項**：Python 的三角函數輸入參數均為**弧度（Radian）**，而非度數（Degree）。
   > 若要將角度轉為弧度，可使用公式：$\text{弧度} = \text{角度} \times \frac{\pi}{180}$。

   [案例]
   > [!example]- 程式碼 trigonometry.py
   > ```python
   > import math
   > # 案例 1：已知角度與斜邊，計算直角三角形的對邊高度 (sin)
   > # 已知角度為 30 度，斜邊長為 10，求對邊高度
   > angle_degrees = 30
   > hypotenuse = 10.0
   > # 1. 將角度轉為弧度
   > radians = angle_degrees * (math.pi / 180)  # 或使用 math.radians(30)
   > # 2. 計算對邊高度 = 斜邊 * sin(角度)  
   > height = hypotenuse * math.sin(radians)
   > print(f"30 度角、斜邊長 10 時的高度為：{height:.2f}")  # 輸出：5.00
   > # 30 度角、斜邊長 10 時的高度為：5.00
   > # 案例 2：利用反切函數 (atan) 反推角度
   > # 已知對邊為 1，鄰邊為 1，求對應的角度
   > tan_value = 1.0
   > # 1. 計算反切函數取得弧度
   > rad_result = math.atan(tan_value)            # 取得弧度 (約 0.7854，即 π/4)
   > # 2. 將弧度轉為角度
   > deg_result = rad_result * (180 / math.pi)     # 轉回角度
   > print(f"tan 答案為 1 時的角度為：{deg_result:.1f} 度")  
   > # tan 答案為 1 時的角度為：45.0 度
   > ```

6. 浮點數絕對值（`fabs`）
   與`Python`內建的`abs()`類似，但`math.fabs()`始終傳回**浮點數 (float)**。

### 3. random 套件函式

亂數函式主要用來產生不同的數值，多用於電腦、統計學、模擬、離散數學、抽樣、作業研究、數值分析、決策等各領域。亂數函式的原型定義在`random`套件中，`random`套件有許多函式提供給使用者使用，如`choice()`、`randint()`、`random()…`。程式若有使用亂數函式時，必須在使用前匯入`random`套件名稱，匯入敘述如下：

### 4. time 套件函式

時間函式是利用時間變化來協助程式進行，以及取得時間、日期…等有關的設計。時間函式的原型定義在`time`套件中，`time`套件提供許多函式給使用者使用，例如 `clock()`、`sleep()`、`time()…`。

程式若有使用時間函式時，必須在使用前匯入 `time` 套件名稱，匯入敘述如下

```python
import time
```

套件名稱在匯入時可以另外取別名，如將 `time` 套件取別名為 `T`，匯入敘述如下：


```python
import time as T
```

### 1.`time()` 函式
   
`time()` 函式是取得電腦目前的時間，即自`1970-01-01 00:00:00`起到目前為止，所經過的秒數。

[例] 取得電腦目前的時間。

>[!example]- 程式碼: time01.py

> import time as T
> num = T.time()

>說明

>   因此`time()`函式傳回的秒數是精確到小數`7`位的浮點數。
>2. 第`3`行:所印出的時間是從`1970-01-01 00:00:00`起到目前的總秒數。

### 2. `ctime()` 函式
   
`ctime()` 函式是取得電腦目前所在時區的日期，時間資料，資料型別為字串。

>說明
>1. 第`2`行:`ctimel()`函式的傳回資料是英文字串,傳回值的格式為`星期月份日時:分:秒 西元年'。
>2. 第`3`行:所印出的時間是目前電腦所在時區的日期、時間資料。

### 3. `localtime()`函式
   
`localctimel()`函式可傳回目前電腦所在時區的日期、時間資訊,這些資訊成員及成員的內容表列如下:

    > | `%Y` | 西元年份，如：'2021' |

    > | `%I` | 時 使用 12 小時制('00' ~ '12') |
    > | `%M` | 分 ('00' ~ '59') |
    > | `%S` | 秒 ('00' ~ '59') |
    > | `%p` | 呈現 'AM' 或 'PM') |
