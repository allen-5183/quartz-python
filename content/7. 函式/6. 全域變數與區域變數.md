## 前言

變數可供多個函式共同使用時，就稱為「全域變數」(`Global variable`)。
變數的有效時間一直到程式結束為止，全域變數必須被建立在所有函式的外面。
在函式內建立的變數，稱為「區域變數」(`Local Variable`) 。此類變數的有效範圍僅在該函式內，離開該函式時此類變數便由記憶體中被釋放掉消失了，下次再執行該敘述區段時，系統會重新配置記憶體給此類變數使用。

## 變數覆蓋

若全域變數與函式內的區域變數使用到相同名稱的變數，則在函式內會產生「變數覆蓋」的現象。兩個同名稱的變數，在記憶體內是佔用不同的位址，互不影響。當程式流程執行到函式時，就使用這個區域所建立的變數，大範圍的全域變數會保留其值，等程式流程離開這較小範圍的函式時，這個區域變數便會消失。待程式流程回到較大範圍程式時，全域變數會仍用原保留的值繼續運作。

[簡例] 建立兩個全域變數、兩個區域變數,其中有一個變數名稱相同。觀察程式執行時它們的有效範圍,並留意變數覆蓋時發生的情況。 (檔名:`global01.py`)

[結果]

```yaml
---- 變數(全域)------------
v1 = 100, v2 = 200

-----變數(全域,區域)------
vl = 31, v2 = 200, v3 = 33

---- 變數(全域)---------
v1 = 100, v2 = 200
```

> [!example]- global01.py
> ```python
> # 定義一個名為 subpro 的函式
> def subpro():
>     # 在函式內部賦值 v1 = 31 和 v3 = 33 時，Python 會自動將它們建立為區域變數（只在這個函式內部有效）。
>     v1 = 31
>     v3 = 33
>     print('----- 變數(全域,區域) -----')
>     """
>     v1：函式內部有自己的區域變數 v1（值為 31），因此會優先使用區域變數，遮蔽外面的全域變數 100。
>     v2：函式內部沒有定義 v2，所以 Python 會向外尋找全域變數 v2（值為 200）。
>     v3：使用函式內部的區域變數 v3（值為 33）。
>     """
>     print(f'v1 = {v1}, v2 = {v2}, v3 = {v3}')
>     print()
>
> # 在函式外部定義了兩個全域變數 v1 = 100 與 v2 = 200。
> v1 = 100
> v2 = 200
> print('----- 變數(全域) -----')
> # 第一次在全域環境中印出變數。
> print(f'v1 = {v1}, v2 = {v2}')
> print()
> # 呼叫並執行 subpro 函式，會執行函式內部的印出動作，輸出 v1 = 31, v2 = 200, v3 = 33。
> subpro()
> # 函式執行完畢後，函式內的區域變數 v1 與 v3 就會被記憶體釋放（消失）。
> print('----- 變數(全域) -----')
> # 再次回到主程式讀取全域變數，全域變數 v1 依然是 100，並沒有因為函式內寫了 v1 = 31 而被修改。
> print(f'v1 = {v1}, v2 = {v2}')
> #print(f'v1 = {V1}, v2 = {v2}, v3 = {v3}')  # 錯誤敘述
> ```

## global 宣告變數

若在函式內使用到全域變數，又要避免發生「變數覆蓋」的現象，則該全域變數在該函式內須用 `global`來宣告。如此這個變數無論在大範圍的主程式或在這小範圍的函式，在記憶體內是占用相同的位址。當程式流程執行這個函式時或離開這個函式時，這個變數皆一直保留其值。

[簡例] 建立兩個全域變數、一個區域變數,其中一個全域變變數要在函式內繼續使用且用`global`宣告。請觀察程式執行時變數值的變化。 (檔名:`global02.py`)

[結果]

```yaml
----- main ----
n = 100, m = 200
---- subpro -----
n = 110, m = 20
----- main ----
n = 110, m = 200
---- subpro -----
n = 120, m = 20
----- main ----
n = 120, m = 200
```

> [!example]- global02.py
> ```python
> def subpro():
>     # 明確宣告 n 屬於全域變數。這代表在函式內對 n 所做的任何修改，都會直接影響並修改外面的全域變數 n
>     global n
>     # 將目前的全域變數 n 加上 10。
>     n = n + 10
>     # 沒有使用 global 宣告，因此這裡的 m 是一個獨立的區域變數（Local Variable），僅在 subpro() 內部有效，不會影響外面的全域變數 m。
>     m = 20
>     print('---- subpro -----')
>     print(f'n = {n}, m = {m}')
>
># 初始化全域變數 n = 100 與 m = 200
> n = 100
> m = 200
> print('----- main -----')
> # 首次印出全域變數。此時 n 為 100，m 為 200。
> print(f'n = {n}, m = {m}')
>  
> """
> 因為有 global n，全域變數 n 被修改為 100 + 10 = 110
> 區域變數 m 設定為 20。
> 函式內部印出：n = 110, m = 20。
> """
> subpro()
> print('----- main -----')
> # 再次印出全域變數。
> """
> n 變成了 110（因為被 subpro 內的 global n 修改了）。
> m 依然是 200（因為函式內的 m = 20 只是區域變數，離開函式後就消失了）。
> """
> print(f'n = {n}, m = {m}')
> # 第二次呼叫 subpro() 函式。
> """
> 此時全域變數 n 從 110 再次加上 10，變成了 110 + 10 = 120
> 區域變數 m 再次被設定為 20。
> 函式內部印出：n = 120, m = 20。
> """
> subpro()
> print('----- main -----')
> # 最後印出全域變數。
> """
> n 變成了 120。
> m 依然維持 200。
> """
> print(f'n = {n}, m = {m}')
> ```
