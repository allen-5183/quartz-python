## 1. 何謂集合

集合(`set`)儲存的是無序列的元素，而且儲存時會自動移除重複的元素，所以在集合中是不存在重複的元素。

```python
# 方法1
集合型別 = {元素1,元素2,…}
# 方法2
集合型別 = set((元素1,元素2,…))
```

1. 使用 **方法1** 建立集合時，其中的元素可以使用的型別為數值、字串和元組。若是 **方法2** 則還可以使用串列，字典。例如:

   ```python
   s1 = (1, 2, 3, 1, 2) # 集合元素為 1、2、3，重複者會被刪除
   s2 = ('A', (2,3), 4) # 集合元素為 'A'、(2,3)、4 
   s3 = set(range(1, 11)) # 集合元素為 1 ~ 10
   s4 = set({1:'A', 2:'B', 3:'C'}) # 集合元素 為1、2、3
   ```

2. 要建立空集合時，一定要使用 **方法2** 寫法如下:

   ```python
   s = set() # 空集合。
   ```

## 2. 集合的基本操作

集合內的元素可以新增刪減，其基本操作語法如下:

| 功能 | 語法說明 |
| :--- | :--- |
| 新增 | **語法**：`集合.add(元素)` |
| 刪除 | **語法**：`集合.remove(元素)` |
| 新增 | **語法**：`集合.update(參數)`<br>**說明**：參數可以是元素或是串列、元組或字典。 |
| 刪除 | **語法**：`集合.discard(元素)`<br>**說明**：同 `remove`，其差異是 `remove` 會產生錯誤訊息，`discard` 則不會。 |
| 刪除 | **語法**：`集合.pop()`<br>**說明**：隨機刪除集合中的一個元素。 |

## 集合的運算

`Python`可以對兩個集合進行聯集、交集、差集和互斥等運算，下表為集合運算常用的方法。

![[assets/3. 集合/IMG-20260722185627220.png|400]]

| 運算 | 說明與範例 |
| :--- | :--- |
| **聯集** | **語法**：`集合 1 | 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.union(集合 2)`<br>**簡例**：`print(set1 | set2)  # {1, 2, 3, 4}`<br>**說明**：兩個集合中所有的元素。 |
| **交集** | **語法**：`集合 1 & 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.intersection(集合 2)`<br>**簡例**：`print(set1 & set2)  # {3}`<br>**說明**：兩個集合中皆有的元素。 |
| **差集** | **語法**：`集合 1 - 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.difference(集合 2)`<br>**簡例**：`print(set1 - set2)  # {1, 2}`<br>**說明**：屬於集合 1 但不屬於集合 2 的元素組成的集合。 |
| **互斥** | **語法**：`集合 1 ^ 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.symmetric_difference(集合 2)`<br>**簡例**：`print(set1 ^ set2)  # {1, 2, 4}`<br>**說明**：集合 1 和集合 2 的元素組成的集合，但不包含兩集合皆有的元素。 |
| **子集合** | **語法**：`集合 1 <= 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.issubset(集合 2)`<br>**簡例**：`set1 = {1, 2}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`set2 = {1, 2, 3}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(set1 <= set2)  # True`<br>**說明**：判斷集合 1 是否為集合 2 的子集合。 |
| **超集合** | **語法**：`集合 1 >= 集合 2`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`集合 1.issuperset(集合 2)`<br>**簡例**：`print(set1 >= set2)  # False`<br>**說明**：判斷集合 2 的所有元素，是否都包含在集合 1 中。 |
