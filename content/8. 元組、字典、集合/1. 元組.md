## 何謂元組

元組(`tuple`)簡單的來說就是由多個元素所組成的群組，元組的成員可以由不同型別的資料型別來組成。元組宣告後就不可以更改，其序列是固定的；讀取元組內含的元素時，使用的註標即建立時的順序。元組與之前介紹的串列結構相同，只是元素個數及元素值都不能改變，所以希望能保護資料時，就可採用元組。

## 元組的宣告

元祖的宣告是以 **「，」** 逗號，區隔各個元素。語法如下:

```python
# 方法 1
元組 = 元素A, 元素B, 元素C, …
# 方法 2
元組 = (元素A, 元素B, 元素C, …)
```

l. 宣告空元組時一定要使用小括號。  

   ```python
   tuple1 =     #錯誤宣告  
   tuple2 = ()  #宣告空元組
   ```

2. 宣告只有一個元素的元組，需要在元素之後加上逗號。  

   ```python
   tuple1 = 25,  
   tuple2 = (25,)
   ```

## 元組常用的函式

下表為元組常用的函式，可用來進行比較元素、元組轉換串列、傳回元組中最大值或最小值...等相關元組的進階操作。

| 函式 | 說明與範例 |
| :--- | :--- |
| `sum()` | **功能**：傳回元組內所有元素的總和，`num` 值為指定參與計算的整數引數，若未指定則預設值為 0。<br>**語法**：`sum(tuple, [num])`<br>**簡例**：`t1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(sum(t1, 40))` `#輸出結果 100` |
| `max()` | **功能**：傳回元組內元素最大者。<br>**語法**：`max(tuple)`<br>**簡例**：`t1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(max(t1))` `#輸出結果 30` |
| `min()` | **功能**：傳回元組內元素最小者。<br>**語法**：`min(tuple)`<br>**簡例**：`t1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(min(t1))` `#輸出結果 10` |
| `tuple()` | **功能**：將串列轉換成元組。<br>**語法**：`tuple(list)`<br>**簡例**：`list1 = [10, 20, 30]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(tuple(list1))` `#輸出結果 (10, 20, 30)` |
| `list()` | **功能**：將元組轉換成串列。<br>**語法**：`list(tuple)`<br>**簡例**：`tuple1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(list(tuple1))` `#輸出結果 [10, 20, 30]` |
| `len()` | **功能**：回傳元組的元素個數。<br>**語法**：`len(tuple)`<br>**簡例**：`tuple1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(len(tuple1))` `#輸出結果 3` |
| `count()` | **功能**：回傳元組中指定元素值的出現次數。<br>**語法**：`tuple.count(元素值)`<br>**簡例**：`tuple1 = (10, 20, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(tuple1.count(20))` `#輸出結果 1` |
| `sorted()` | **功能**：將元組中元素遞增排序後回傳，回傳值為串類型別。<br>**語法**：排序後串列 = `sorted(tuple)`<br>**簡例**：`tuple1 = (20, 10, 30)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(sorted(tuple1))` `#輸出結果 [10, 20, 30]` |

## 元組基本操作

元組在程式中可以進行簡單的操作，以下用實例配合說明，來瞭解元組的基本操作。

[例] 元組基本操作。 (`tuple_1.py`)

> [!example]- tuple_1.py
> ```python
> tuple1 = ('東','南','西')
> print(tuple1)
> East,South,West = tuple1
> print(South)
> tuple2 = tuple1 + ('北',) 
> print(tuple2)
> tuple1,tuple2 = tuple2,tuple1
> print(tuple1)
> print(tuple2)
> print(len(tuple1))
> del(tuple2)
> #print(tuple2) #
> list1 = list(tuple1)
> list1.append('東北')
> print(list1)
> tuple1 = tuple(list1)
> print(tuple1)
> print(tuple1[0])
> print('東北' in tuple1)
> for t in tuple1:
>    print(t, end=',')
> ```

[簡例] 請撰寫程式從二維元組中讀取購物清單,清單內的資料分別是品名、數量及單價。顯示清單上的資料並計算小計,最後計算總計。 (`shop.py`)

[結果]

```yaml
品 名  數 量  單價  小計
 香蕉    34     2   68
 芭樂    28     3   84
 水梨    50     2  100
總 計:             252
```

> [!example]- shop.py
> ```python
> # -*- coding: utf-8 -*-
> data = (('香蕉', 34, 2), ('芭樂', 28, 3), ('水梨', 50, 2))
> total = []
> print ('品  名\t數  量\t單  價\t小  計')
> for t1 in data:
>     name,s1,s2 = t1
>     total.append(s1 * s2)
>     print(f'{name:>4}{s1:8}{s2:8}{total[-1]:8}')
> print(f'總  計:{sum(total):23}')     
> ```
