## 何謂字典

字典(`dict`)的每個元素是用冒號「:」分隔，冒號之前是鍵(`Key`)，冒號之後是值(`Value`)，換言之是由「鍵:值」組成一個元素。元素間用逗號「,」分隔，所有元素被「{}」大括號包圍，即完成字典型別。字典顧名思義，就像我們使用的字典，可以根據英文單字查詢到中文解釋，例如`book` 對應到 「書本」，如果用字典語法可以寫成 `{'book':'書本'}`。真實的字典是依規則排序以方便查詢，但是`Python` 中字典的元素是無序列儲存的，其語法如下: 

```python
字典 = {鍵1:值1, 鍵2:值2, …}
```

1. 鍵必須是唯一而且不可變的，而鍵可以使用的型別為數值、字串或元組。
2. 值可以是任何資料型別，除了常用型別外，串列、元組、字典...等也可以。

## 字典基本操作

字典在程式中可以進行元素的新增、修改及刪除等操作，語法如下：

| 功能 | 語法說明 |
| :--- | :--- |
| 修改 | 語法：`字典[鍵] = 新值` |
| 刪除 | 語法：`del 字典[鍵]` `#刪除字典中某一元素`<br>語法：`del 字典` `#刪除整個字典` |
| 新增 | 語法：`字典[新鍵] = 值` |

[例] 字典基本操作。 (`dict_1.py`)

> [!example]- 程式碼: dict_1.py
> ```python
> dict1 = {'一月':'正月','二月':'花月','三月':'梅月'}
> print(dict1)
> print(dict1['三月'])
> dict1['一月'] = '端月' 
> print('一月是', dict1['一月'])
> del dict1['一月']
> print(dict1)
> dict1['一月'] = '正月' 
> print(dict1)
> print('1月' in dict1)
> del dict1
> #print(dict1)
> ``` 

## 字典進階操作

`Python` 的字典型別內建許多方法，方便我們進行進階操作。

| 方法 | 功能說明 |
| :--- | :--- |
| `dict` | **功能**：建立一個新字典。<br>**語法**：`dict(元組或串列)`<br>**簡例**：`dict1 = dict((('一月','正月'),('二月','花月')))`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict1)  #輸出結果 {'一月': '正月', '二月': '花月'}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`dict1 = dict([['一月','正月'],['二月','花月']])`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict1)  #輸出結果 {'一月': '正月', '二月': '花月'}`<br>**說明**：運用 `dict()` 函式轉換元組和串列為字典，傳入資料必須成對，前者轉換成字典的鍵，後者轉換為值。 |
| `fromkeys` | **功能**：建立一個新字典。<br>**語法**：`dict.fromkeys(元組或串列[, 預設值])`<br>**簡例**：`dict2 = dict.fromkeys(('四月','五月'))`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict2)  #輸出結果 {'四月': None, '五月': None}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`dict2 = dict.fromkeys(['一月','四月'],'端月')`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict2)  #輸出結果 {'一月': '端月', '四月': '端月'}`<br>**說明**：以 `fromkeys` 轉換元組或串列為字典的鍵，所有鍵的值為第二個參數，若省略第二參數，預設為「`None`」。 |
| `keys` | **功能**：傳回字典中所有的鍵。<br>**語法**：`字典.keys()`<br>**簡例**：`print(dict1.keys())  #輸出結果 dict_keys(['一月', '二月'])`<br>**說明**：顯示 `dict1` 字典中所有的鍵。 |
| `values` | **功能**：傳回字典中所有的值。<br>**語法**：`字典.values()`<br>**簡例**：`print(tuple(dict1.values()))  #輸出結果 ('正月', '花月')`<br>**說明**：顯示 `dict1` 字典中所有的值。 |
| `items` | **功能**：傳回字典中所有的元素。<br>**語法**：`字典.items()`<br>**簡例**：`print(list(dict1.items()))  #輸出結果 [('一月', '正月'), ('二月', '花月')]`<br>**說明**：顯示 `dict1` 字典中所有的元素。 |
| `get` | **功能**：傳回字典中指定鍵所對應的值。<br>**語法**：`字典.get(key[, value])`<br>**簡例**：`print(dict2.get('三月'))  #輸出結果 None`<br>**說明**：`get` 用來查詢「三月」是否為字典的鍵，如果有就傳回其對應的值；如果不是則傳回第二個參數，若省略第二參數，預設為「`None`」。 |
| `setdefault` | **功能**：傳回字典中指定鍵所對應的值，如果該鍵不存在會新增該鍵。<br>**語法**：`字典.setdefault(key[, value])`<br>**簡例**：`print(dict2.setdefault('一月', '梅月'))  #輸出結果 端月`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict2)  #輸出結果 {'一月': '端月', '四月': '端月'}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict2.setdefault('三月', '梅月'))  #輸出結果 梅月`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict2)  #輸出結果 {'一月': '端月', '四月': '端月', '三月': '梅月'}`<br>**說明**：`setdefault` 和 `get` 的功能類似，其差異點是如果鍵不存在 `setdefault` 會新增以 `key` 為鍵的新元素。而第二個參數設定為該元素的值，若省略第二參數，預設值為「`None`」。 |
| `pop` | **功能**：傳回字典中指定鍵所對應的值，並刪除該元素。<br>**語法**：`字典.pop(key[, value])`<br>**簡例**：`dict1.pop('10 月', 'NONE')`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`dict1.pop('四月')`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict1)  #輸出結果 {'一月': '端月', '二月': '花月', '三月': '梅月'}`<br>**說明**：使用 `pop` 時，如果鍵存在，回傳其值，之後刪除此元素；如果鍵不存在，回傳第二參數，此時如果第二參數省略會產生錯誤訊息。若字典內無元素則會產生錯誤訊息。 |
| `popitem` | **功能**：隨機傳回字典中的元素，並刪除該元素。<br>**語法**：`字典.popitem()`<br>**簡例**：`print(dict1.popitem())  #輸出結果 ('三月', '梅月')`<br>**說明**：使用 `popitem` 不用參數，因為這方法會隨機傳回一個元素，再刪除該元素。該留意的是如果使用於空字典，會產生錯誤訊息。 |
| `update` | **功能**：以 `dict2` 中的元素，更新 `dict1`。<br>**語法**：`dict1.update(dict2)`<br>**簡例**：`dict1.update(dict2)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict1)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`#輸出 {'一月':'端月','二月':'花月','四月':'端月','三月':'梅月'}`<br>**說明**：`update` 會將 `dict2` 與 `dict1` 合併，假使 `dict2` 有 `dict1` 不存在的鍵，則新增該元素到 `dict1`；反之以 `dict2` 的值覆蓋 `dict1` 該元素的值。 |
| `clear` | **功能**：清除字典內所有元素。<br>**語法**：`字典.clear()`<br>**簡例**：`dict1.clear()`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`print(dict1)  #輸出結果 {}`<br>**說明**：`clear` 會刪除字典內所有元素，使其成為僅保留名稱的空字典。 |

[簡例] 使用者可以輸入貨號,查詢品名和售價。如果該貨號不存在,則可以新增資料。 (檔名:`search.py`)

```yaml

貨號 : A003 品名: 冰棒售價 : 20 元
```

```yaml

請輸入品名 : 豆干

貨號 : A002 品名 : 豆干售價 : 15 元
```

> [!example]- 程式碼: search.py
> ```python
> datas = {'A001':['汽水',25],'A005':['公主麵',10],
>          'A006':['口香糖',8],'A003':['冰棒',20]}
> num=input('請輸入貨號：')
> if num not in datas:
>     print(f'貨號：{num} 不存在')
>     name=input('請輸入品名：')
>     money=int(input('請輸入售價：'))
>     datas[num]=[name,money]
> d = datas.get(num)
> print(f'貨號：{num} 品名：{d[0]} 售價：{d[1]}元')
> ```
