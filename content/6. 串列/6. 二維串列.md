## 二維串列

二維串列的註標有兩組，第一組註標稱為「列」(`row`) ，第二組註標稱為「行」(`column`)。凡是能以表格方式呈現的資料，都可以使用二維串列，如：座位表、課表…。二維串列中若每一列的個數都相同，就構成了一個矩陣串列。

二維串列的建立語法如下：

```python
串列名稱 = [[元素 00,元素 01,元素 02,⋯],[元素 10,元素 11,元素 12,⋯],
           [元素 20,元素 21,元素 22,⋯], ..........]
```

[例] 建立宣告一個名稱為`lst`的二維串列,其串列大小為`3`列`4`行,元素存放整數資料。取得`lst`串列元素内容,使用`len()`測得串列大小。(檔名: `2list.py`)

> [!example]- 程式碼: `2list.py`
> ```python
> # 建立一個二維陣列
> lst = [[4,8,5,9],[13,16,19,15],[28,25,29,24]]
> print(lst)      # 印出 [[4,8,5,9],[13,16,19,15],[28,25,29,24]]
> # 取得串列第一維的大小
> n1 = len(lst)   # n1 ← 3
> # 取出第 2 個 row 的資料 
> print(lst[0])   # 印出 [4, 8, 5, 9]
> print(lst[1])   # 印出 [13, 16, 19, 15]
> print(lst[2])   # 印出 [28, 25, 29, 24]
> # 取得串列第二維的大小，該 row 有 lst[1][0],lst[1][1],lst[1][2],lst[1][3]  三個元素
> n2 = len(lst[1]) # n2 ← 4
> print(lst[1][2]) # 印出 19
>```

>說明:
>
>&emsp;|第1行[0]|第2行[1]|第3行[2]|第4行[3]|
>-----|---------|--------|--------|---------
>第1列[0]|<center>4</center>|<center>8</center>|<center>5</center>|<center>9</center>
>第2列[1]|<center>13</center>|<center>16</center>|<center>19</center>|<center>15</center>|
>第3列[2]|<center>28</center>|<center>25</center>|<center>29</center>|<center>24</center>|

[簡例] 使用迴圈從已初始化的串列中讀取所有元素的資料。 (檔名:`readList.py`)

> [!example]- 程式碼: `readList.py`
> ```python
> lst = [[4,8,5,9],[13,16,19,15],[28,25,29,24]]
> 
> print('lst =', end = ' ')
> print(lst)
> for i in range(len(lst)):
>     print()
>     for j in range(len(lst[i])):
>         print(f'lst[{i}][{j}]={lst[i][j]:2d}', end = '   ')
> ```

[結果]

[例] 用串列生成器建立二維串列`arr`，使其內容為`[[0, 0],[0, 0],[0, 0],[0, 0]]` 檔名: `list8.py`

> [!example]- 程式碼: `list8.py`
> ```python
> # 用串列生成器建立一維陣列，2 個元素，並使元素內容為 [0, 0]
> # 建立一個一維陣列 A[], 迴圈跑 2 次，每一次放 0，  所以得到 A = [0, 0] 
> A = [0 for x in range(2)]
> print(A)                      # 印出 [0,0]
> # 建立一個一維陣列 arr[], 迴圈跑 4 次，每一次放 先前建立好的 A 元素 [0, 0]
> arr = [A for y in range(4)]
> print(arr)                    # 印出 [[0,0],[0,0],[0,0],[0,0]]
> ```

[簡例] 下表為四位考生參加資優評選的成績,請完成空白部份的數據。 (檔名:`score.py`)
> [!example]- 程式碼: `score.py`
> ```python
> no = [1,2,3,4]                                           # 編號
> score = [[87,64,88],[93,72,86],[80,88,89],[79,91,90]]    # 成績   
> print('編號   語文   數理   智力   總分')
> print('================================') 
> # 迴圈跑 len(no)=4 次， i =0, 1, 2, 3
> for i in range(len(no)):
>     # 印出 編號 1, 2, 3, 4 (2 位數字)
>     print(f'{no[i]:2d}', end = '    ')
>     hSum = 0
>     # j = 0, 1, 2, 3
>     # 計算每一 row 加總成績 for 每一編號學生
>     for j in range(len(score[i])):
>         print(f'{score[i][j]:3d}', end = '    ')
>         hSum += score[i][j]
>     print(f'{hSum:3d}')
>
> print('平均', end = '   ')
> # j = 0, 1, 2
> for j in range(3):
>     vSum = 0
>     # i = 0, 1, 2    j = 0
>     # i = 0, 1, 2    j = 1
>     # i = 0, 1, 2    j = 2     
>     for i in range(len(no)):
>         vSum += score[i][j]
>     # 平均 = ([0][0] + [1][0] + [2][0] + [3][0]) / 4 
>     # 平均 = ([0][1] + [1][1] + [2][1] + [3][1]) / 4 
>     # 平均 = ([0][2] + [1][2] + [2][2] + [3][2]) / 4    
>     print(f'{vSum/len(no):4.1f}', end = '   ')
>```

[結果]

```yaml
編號   語文   數理   智力   總分
================================
 1     87     64     88    239
 2     93     72     86    251
 3     80     88     89    257
 4     79     91     90    260
平均   84.8   78.8   88.2   
```
