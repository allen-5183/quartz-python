## 一維串列

### 1. 一維串列的建立

一維串列的建立方式是以 **[]** 運算子來存放元素資料，元素間再用逗號分隔，語法為：

```python
串列名稱 = [元素 1, 元素 2, 元素 3]
```

[例] 建立串列名稱`score`,其元素內容分別為`83`、`79`、`90`、`87`整數資料。

![[assets/1. 何謂串列/IMG-20260721185235244.png|400]]

>說明
>1. 串列中各個元素資料的型别可以相同,也可以不相同。
>   例: score  = [72,98,86,76] # 元素皆為整數資料型別
>   例: animal = ['cat','dog', 'monkey', 'tiger'] # 元素皆為字串資料型別
>   例: data = ['Mary',45,True] # 元素存放的資料型別不相同
>2. 串列建立時,也可以不含元素資料。
>   例: list1 = [] # 建立的 list1 串列是空串列

### 2. 串列的讀取與存放

利用`[]` 運算子填入註標，可對串列存取其對應的元素內容；若是使用 `[start:end]`，便是存取註標 `strat` 起至註標 `end-1` 的串列元素。要注意的是，串列中第一個元素的註標是`0`，第二個元素的註標是`1`，以此類推…。

1. 讀取串列元素
   讀取串列元素的語法為：

   ```yaml
   語法1: 串列名稱[註標]

   語法2: 串列名稱[start:end:step]
   ```

   >1. 語法1：可以讀取註標值所對應的串列元素，註標不能超過範圍，否則程式執行時會產生錯誤。
   >2. 語法2：讀取`strat`起到`end-1` 註標之間的串列元素，`step`為間隔值。若 `strat` 省略，預設值為`0`；若`end`省略，則預設值為串列長度；若`step`省略，則預設值為`1`。

   [例]建立串列Istl,並進行相關的串列元素讀取操作。(檔名:`listl.py`)       
   >[!example]- 程式碼: `listl.py`
   >```python
   >lst1 = [11, 22, 33, 44, 55, 66, 77, 88, 99]
   >print(lst1)               # 印出 [11, 22, 33, 44, 55, 66, 77, 88, 99]
   >print(lst1[0])     # 印出 11 
   >print(lst1[3])     # 印出 44
   >print(lst1[2:6])   # 印出 [33, 44, 55, 66]
   >print(lst1[:6])    # 印出 [11, 22, 33, 44, 55, 66]
   >print(lst1[0:9])   # 印出 [11, 22, 33, 44, 55, 66, 77, 88, 99]
   >print(lst1[1:9:2]) # 印出 [22, 44, 66, 88]
   >print(lst1[1::2])  # 印出 [22, 44, 66, 88]
   >print(lst1[-1])    # 印出 99
   >print(lst1[-9])    # 印出 11
   >print(lst1[-6:-3]) # 印出 [44, 55, 66]
   >print(lst1[:-2])   # 印出 [11, 22, 33, 44, 55, 66, 77]
   >print(lst1[10])    # 錯誤，註標超過範圍
   ```

2. 存放串列元素
   串列在建立時已存放有元素的初值,但如同變數一樣,所存放的元素值可以再改變內容,其改變元素內容的語法為:

   ```python
   串列名稱[註標] = 資料
   ```

   [例] 建立串列`list2`,並進行相關的串列元素存放操作。(檔名:`list2.py`)

   > [!example]- 程式碼:`list2.py`
   >```python
   >list2 = ['one', 'two', 'three', 'four', 'five', 'six']      
   >list2[3] = '四'  # list2[3] 的內容由 'four' 更改為 '四' 
   >print(list2[3])  # 印出 四
   >print(list2)     # 印出 ['one', 'two', 'three', '四', 'five', 'six']
   ```
