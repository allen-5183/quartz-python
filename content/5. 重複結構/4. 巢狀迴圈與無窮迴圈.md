## 1. 巢狀迴圈

若迴圈內還有迴圈，一層一層由內而外即構成「巢狀迴圈」(`Nested loop`)，也可以稱為「多重迴圈」。無論是`for`或`while`迴圈，或是同時使用都可以構成巢狀迴圈。撰寫巢狀迴圈程式時，要特別注意縮排程式才能正確執行。

[例] 試以巢狀迴圈顯示直角三角形。(檔名:`n_loop.py`)
> [!example]- 程式碼: `n_loop.py`
> ```python
> for x in range(1, 6):
>      for y in range(1, 6 - x):
>          print(' ', end='')
>      for y in range(1, x + 1):
>          print('*', end = '')
>      print ( )
> ```

## 2. 無窮迴圈

假使迴圈的條件式永遠為`True`(真)，會形成無窮迴圈，程式流程會周而復始的執行迴圈區塊。因此撰寫無窮迴圈內的迴圈區塊時，必需有改變條件的敘述，或者使用`break`作為脫離迴圈的出口。

[例] 如下簡例為無窮迴圈的程式。(檔名:`while_3.py`)
> [!example]- 程式碼: `while_3.py`
> ```python
> i = 1
> sum = 0
> while(i <= 10):
>      sum += i
> i += 1
> print (sum)
> ```

[簡例] 重複結構來列印九九乘法表 (檔名:`loop.py`)
> [!example]- 程式碼: `loop.py`
> ```python
> for i in range(10):
>   if(i <= 0):
>       continue
>   j = 1
>   while 1:
>      print(i, '*', j, '=', i*j, end='\t')
>      j = j + 1
>      if(j > 9):
>          break
>   print()
> ```
