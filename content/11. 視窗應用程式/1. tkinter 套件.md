## tkinter 套件簡介與匯入

`tkinter`是`Python`所提供的標準`GUI(Graphical User Interface)`圖形化使用者介面，核心基於 Tcl/Tk，`Python`透過`tkinter`可快速建立`GUI`應用程式。
此套件是跨平台的`GUI`套件，能夠在`Mac`、`Windows`、`Linux`等平台上開發視窗應用程式，安裝`Anaconda`預設即會安裝`tkinter`套件，使用時可先行匯入，其寫法如下：

```python
import tkinter as tk
```

 如上寫法即是在匯入`tkinter`套件同時即命名別名為「**tk**」，之後即可直接使用`tk`進行建立視窗程式。


## 如何建立視窗

使用`Python`配合`tkinter`套件建立視窗程式非常簡單，只要透過下面程式即可建立一個視窗應用程式，並指定該視窗標題為「第一個視窗應用程式」，同時指定視窗大小寬`400`px，高`200`px。(檔名：`window01.py`)

> [!example]- 程式碼: window01.py 
> ```python
> import tkinter as tk
>
> # 呼叫 tk.Tk() 類別來建構一個主視窗物件，並指派給變數 win。這一行會正式啟動視窗元件的初始化。
> win = tk.Tk()
> # 設定主視窗頂部標題列顯示的文字為 '第一個視窗應用程式'
> win.title('第一個視窗應用程式')
> # 設定視窗開啟時的初始尺寸，格式為 '寬x高'（單位為像素）
> win.geometry('400x200')
> # 啟動視窗的**事件循環（Event Loop）**。這會讓視窗保持開啟並持續監聽使用者的操作(例如滑鼠點擊、按鍵或縮放視窗）。如果沒有這一行，視窗建立後就會立刻關閉並結束程式。
> win.mainloop()
> ```

## tkinter 套件常用元件

`tkinter`套件提供多種元件讓開發人員使用，如按鈕、標籤或文字方塊…等，下表為本章介紹且常用的元件。

| 元件名稱 | 說明 |
| :--- | :--- |
| Button<br>按鈕 | 在應用程式中建立按鈕。 |
| Checkbutton<br>核取按鈕 | 在應用程式中建立核取按鈕，讓使用者進行多選項項目。 |
| Entry<br>文字方塊 | 在應用程式中建立文字方塊，讓使用者輸入資料。 |
| Label<br>標籤 | 在應用程式中建立標籤，用來顯示應用程式相關訊息。 |
| Radiobutton<br>選項按鈕 | 在應用程式中建立選項按鈕，讓使用者進行單選項項目。 |
| messagebox<br>訊息方塊 | 用來顯示應用程式的相關提示訊息。 |

以上元件都是`tkinter`內建的傳統元件，外觀較陽春。實務上的視窗應用程式更常改用外觀貼近作業系統原生樣式的「主題化元件」，即`tkinter.ttk`模組，並額外提供`Combobox`（下拉式選單）、`Treeview`（表格清單）、`LabelFrame`（群組框）等元件，詳見〈11. ttk 主題元件套件〉。
