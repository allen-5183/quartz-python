## tkinter 套件簡介與匯入

`tkinter`是`Python`所提供的標準`GUI(Graphical User Interface)`圖形化使用者介面，`Python`透過`tkinter`可快速建立`GUI`應用程式。
此套件是跨平台的`GUI`套件，能夠在`Mac`、`Windows`、`Linux`等平台上開發視窗應用程式，安裝`Anaconda`預設即會安裝`tkinter`套件，使用時可先行匯入，其寫法如下：

```python
import tkinter as tk
```

 如上寫法即是在匯入`tkinter`套件同時即命名別名為「**tk**」，之後即可直接使用`tk`進行建立視窗程式。


## 如何建立視窗

使用`Python`配合`tkinter`套件建立視窗程式非常簡單，只要透過下面程式即可建立一個視窗應用程式，並指定該視窗標題為「第一個視窗應用程式」，同時指定視窗大小寬`400`px，高`200`px。(檔名：`window01.py`)

> [!example]- 程式碼: `window01.py` 
> ```python
> import tkinter as tk
>
> win = tk.Tk()
> win.title('第一個視窗應用程式')
> win.geometry('400x200')
> win.mainloop()
> ```

## tkinter 套件常用元件

`tkinter`套件提供多種元件讓開發人員使用，如按鈕、標籤或文字方塊…等，表是本章介紹且常用的元件。

| 元件名稱 | 說明 |
| :--- | :--- |
| Button<br>按鈕 | 在應用程式中建立按鈕。 |
| Checkbutton<br>核取按鈕 | 在應用程式中建立核取按鈕，讓使用者進行多選項項目。 |
| Entry<br>文字方塊 | 在應用程式中建立文字方塊，讓使用者輸入資料。 |
| Label<br>標籤 | 在應用程式中建立標籤，用來顯示應用程式相關訊息。 |
| Radiobutton<br>選項按鈕 | 在應用程式中建立選項按鈕，讓使用者進行單選項項目。 |
| messagebox<br>訊息方塊 | 用來顯示應用程式的相關提示訊息。 |
