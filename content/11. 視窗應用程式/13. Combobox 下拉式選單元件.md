當某個欄位的值只能限定在幾個固定選項裡（例如性別只能是`F`或`M`、縣市只能是台灣的幾個城市），若用〈7. Radiobutton 選項按鈕元件〉逐一列出每個選項，選項一多畫面就會被占滿；這種情況更適合使用`Combobox`下拉式選單，把所有選項收合在一個下拉清單裡，使用者點開後選取其中一項即可，比較省版面。`Combobox`是`ttk`模組提供的元件（`tkinter`本身沒有），建立語法如下：

```python
物件變數 = ttk.Combobox(容器物件, [參數1=值1, 參數2=值2, …, 參數n=值n])
```

## 常用參數

| 參數 | 說明 |
| :--- | :--- |
| `values` | 設定下拉清單中的選項內容，型別為串列（`list`），例如`values=['F', 'M']`。 |
| `textvariable` | 代表下拉選單目前選取值的物件，用法與`Entry`的`textvariable`相同，須先用`tkinter`模組的`StringVar()`等方法定義變數，再透過`var.get()`取得目前選取的值，`var.set(值)`可用程式指定選取的值。可參考〈5. Entry 文字方塊元件〉。 |
| `width` | 設定下拉選單的寬度。 |
| `state` | 設定下拉選單的狀態，預設值`'normal'`表示使用者除了下拉選取，也可以自行在欄位中輸入文字；設為`'readonly'`表示唯讀，使用者只能從`values`清單中挑選，無法自行輸入其他字串（常用於避免使用者輸入不在允許範圍內的值，例如資料庫欄位限定只能存`ENUM('F','M')`時）。 |

當`Combobox`綁定了`textvariable`之後，除了透過變數的`get()`／`set()`存取目前選取值，元件本身也提供對應的`get()`／`set()`方法可以直接使用，兩種寫法效果相同：

```python
vSex = var_sex.get()      # 透過變數取得目前選取值
vSex = cboSex.get()       # 或直接呼叫 Combobox 物件的 get()
```

[簡例] 建立城市下拉選單，預設選取`台北市`，選取後按下[確定]鈕以對話方塊顯示選取的城市。(檔名:`combobox01.py`)

> [!example]- 程式碼: `combobox01.py`
> ```python
> import tkinter as tk
> from tkinter import ttk, messagebox
>
> def fnOk():
>     messagebox.showinfo('選取結果', f'你選取的城市是：{city.get()}')
>
> win = tk.Tk()
> win.title('Combobox 範例')
> win.geometry('260x100')
>
> lblCity = ttk.Label(win, text='居住城市:')
> lblCity.pack(side='left', padx=10, pady=20)
>
> city = tk.StringVar(value='台北市')
> cboCity = ttk.Combobox(win, textvariable=city,
>                         values=['台北市', '新北市', '台中市', '台南市', '高雄市'],
>                         width=10, state='readonly')
> cboCity.pack(side='left')
>
> btnOk = ttk.Button(win, text='確定', command=fnOk)
> btnOk.pack(side='left', padx=10)
>
> win.mainloop()
> ```

[結果]
（可自行執行程式碼查看畫面：下拉選單預設顯示「台北市」，點開後可選取其他四個城市。）

> 說明
> 1. 第`14`行：建立`city`這個`tk.StringVar()`物件，並在建立時透過`value='台北市'`指定預設選取值。
> 2. 第`15~18`行：建立`cboCity`下拉選單，`values`指定五個城市選項，`textvariable=city`把選單與`city`變數綁定，`state='readonly'`限制使用者只能從清單中選取，不能自行輸入其他文字。
> 3. 第`4~5`行：定義`fnOk()`函式，用`city.get()`取得目前選取的城市並顯示於對話方塊。

## 在 student_crud.py 的應用

[student_crud.py](assets/student_crud.py)的`_build_form()`方法中，「性別」欄位就是用`Combobox`限定只能選`F`或`M`，對應資料表`cSex`欄位為`ENUM('F','M')`的設計：

```python
self.var_sex = tk.StringVar(value='F')
ttk.Combobox(row0, textvariable=self.var_sex, values=['F', 'M'], width=5, state='readonly').pack(side='left', padx=5)
```

因為資料庫欄位限定只能存`'F'`或`'M'`，所以用`state='readonly'`避免使用者透過鍵盤輸入這兩個值以外的文字，寫入資料庫時觸發錯誤。
