使用`Label`標籤控制項可在視窗上提供輸出入訊息，譬如提示訊息。亦可用來顯示程式執行過程或最後結果的相關訊息，但要注意標籤控制項只能顯示文數字資料，無法透過鍵盤來輸入資料。建立標籤的語法如下：

```python
物件變數 = tkinter.Label(容器物件, [參數1=值1, 參數2=值2, …, 參數n=值n])
```

`tkinter`套件的`Label()`方法可在指定的容器物件上建立標籤，還可透過參數對標籤進行相關設定，如寬、高、背景色或文字顏色…等，常用的參數如下。
(表中參數亦可在`Entry`、`Button`、`Checkbutton`、`Radiobutton`元件中使用)

| 參數 | 說明 |
| :--- | :--- |
| **text** | 設定元件內的文字。 |
| **width** | 設定元件的寬度。 |
| **height** | 設定元件的高度。 |
| **background** 或 **bg** | 設定元件的背景顏色。 |
| **foreground** 或 **fg** | 設定元件的文字顏色。 |
| **padx** | 設定文字或內容與元件的水平台間距。 |
| **pady** | 設定文字或內容與元件的垂直間距。<br><br>如下寫法在 win 視窗上建立背景色為粉紅色 Python 的標籤：<br>`lbl01 = tk.Label(win, text='Python', bg='pink')`<br>![[assets/2. Label 標籤元件/IMG-20260723181045664.png]]<br>如下寫法在 win 視窗上建立背景色為粉紅色 Python 的標籤，同時指定水平台間距為 30，垂直間距為 50。<br>`lbl01 = tk.Label(win, text='Python', bg='pink', padx=30, pady=50)`<br>![[assets/2. Label 標籤元件/IMG-20260723181218248.png]] |
| **font** | 設定元件的字型與大小。例如設定字型為標楷體，字體大小為 14。寫法：`font=('標楷體', 14)`。 |
| **image** | 使用圖片代表標籤的內容。可參考 11.9 節。 |

當元件放置於指定的容器物件上時,還必須使用`pack()`方法設定元件的編排位
置,`pack()`方法預設的放置方式是由上到下。

[簡例] 使用`Label`元件建立三個課程名稱並依序指定背景色為粉紅色、黃色、紅色,字體大小依序指定為`16`、`14`、`11`,字型皆為標楷體。(檔名:`label01.py`)

[結果]
![[assets/2. Label 標籤元件/IMG-20260723181552156.png]]

> [!example]- 程式碼: `label01.py` 
> ```python
> import tkinter as tk
>
> win = tk.Tk()
> win.title('標籤元件')
> win.geometry('400x100')
> lbl01 = tk.Label(win, text='跟著實務學習ASP.NET Core MVC', bg='pink',font=('標楷體', 16))
> lbl02 = tk.Label(win, text='跟著實務學習網頁設計', bg='yellow',font=('標楷體', 14))
> lbl03 = tk.Label(win, text='跟著實務學習Bootstrap', bg='red', fg='white',font=('標楷體', 11))
> lbl01.pack()
> lbl02.pack()
> lbl03.pack()
> win.mainloop()
> ```

> 說明
> 1. 第`1`行:匯入`tkinter`套件並以`tk`為別名。
> 2. 第`6-8`行: 使用`Label()`建立`lb101`、`lb102`、`lb103`標籤物件,並依序指定背景色為粉紅色、黃色、紅色,字體大小依序為`16`、`14`、`11`,字型皆為標楷體。
> 3. 第`9~11`行: 用`pack()`方法將`lb101`、`lb102`、`lb103`標籤在`win`視窗中由上到下放置。
