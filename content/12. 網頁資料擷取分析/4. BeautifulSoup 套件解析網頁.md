**BeautifulSoup** 套件可用來解析網頁，此套件在安裝`anaconda`套件時即會同時安裝，**BeautifulSoup** 套件提供的 **BeautifulSoup()** 函式可傳回**BeautifulSoup** 物件，其語法如下：

```python
from bs4 import BeautifulSoup # 由bs4匯入BeautifulSoup 套件
......
物件變數=BeautifulSoup(解析的程式碼字串',
```

`BeautifulSoup` 物件提供如下屬性與方法,可解析網頁程式碼:

| 屬性與方法 | 說明 |
| :--- | :--- |
| `title` 屬性 | 傳回網頁的標題，即 html 網頁的 `<title>~</title>` 資料。 |
| `text` 屬性 | 傳回網頁去除 html 標籤後的內容。 |
| `find('標籤')` 方法 | 傳回第一個符合的 html 標籤內容，若找不到會傳回 None。 |
| `find_all('標籤')` 方法 | 傳回所有符合的 html 標籤內容，若找不到會傳回 None。 |
| `select('選擇器')` 方法 | 傳回指定選擇器的網頁資料(即網頁程式)，選擇器使用如下：<br>● `select('標籤')`：標籤選擇器。<br>● `select('#id 名稱')`：id 選擇器，id 名稱前要加上 # 號。<br>● `select('.class 名稱')`：類別選擇器，類別名稱前要加上「.」號。 |
