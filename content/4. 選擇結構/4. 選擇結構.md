## 選擇結構

由上而下一行接一行逐行執行，即使再執行一次其流程仍不會改變，此種程式架構稱為「循序結構」。

較複雜的程式會應程式的需求，依照條件式的不同而進行不同的執行流程，而得到不同的結果，這種架構就是「選擇結構」。

`Python`提供的 `if` 選擇結構敘述如下：

1. 單向選擇： `if …` 
2. 雙向選擇： `if … else …`
3. 巢狀選擇： `if … else …`
4. 多向選擇： `if … elif … else`

選擇結構中會有條件式，依照條件式的不同會執行不同的程式流程。條件式可以使用前面介紹的關係和邏輯運算式來編寫。

### 1.  單向選擇 if…

所謂 「單向選擇」是指當 `if` 的條件式成立為 `True`  時，會執行 `if` 條件式「:」冒號後面縮排的敘述區段；若if的條件式不成立為 `False` 時，則跳過 `if` 單向選擇結構，執行縮排敘述區段後的敘述。語法及流程圖如下：
![[assets/1. 結構化程式設計/IMG-20260718225714741.png|400]]

[例] 求`num`的絕對值
> [!example]- 程式碼
>```python
>if (num < 0) :   # 省略左右括號()亦可寫為 if num < 0 :
>   num = -num
>```   

[例] 成績在`55`分以上未達`60`分者,以`60`分計分。
> [!example]- 程式碼
>```python
>if ((score >= 55) and (score < 60)) :
>    score = 60
>    print('差強人意,通融過關')
>```

>`Python3.8`中新增「`:=`」指定表式(`Assignment Expressions` 或稱指派表示式),因為符號很像海象臉部的眼睛和長牙,因此被暱稱為海象運算子。指定表式可縮短程式碼加快執行速度,但會降低可讀性,可自行視需求使用。例如:

> [!example]- 程式碼
> ```python
> score = 65
> if (score >= 60):
>     print('及格')
> ```
> 使用海象運算子時,可以改寫為:
> ```python
> if ((score := 65) >= 60):
>     print('及格')
> ```

### 2. 雙向選擇 if…else…

「雙向選擇」是指當條件式成立時，執行 if 條件式「:」冒號後面的敘述區段1；若條件式不成立時，則執行 else 「:」冒號後的敘述區段2。

語法及流程圖如下：
![[assets/1. 結構化程式設計/IMG-20260718230147931.png|400]]

[例] 門票`300`元,若年齡低於`10`歲或`65`歲以上半價。

 > [!example]- 程式碼
 > ```python
 > if (age < 10 or age >= 65) :
 >     price = 150
 > else :
 >     price = 300
 > ```

[例] 根據成績及格或不及格,給予不同回饋。

 > [!example]- 程式碼
 >```python
 >if (score > 60):
 >    print('及格')
 >    print('恭喜過關!')
 >else :
 >    print('不及格')
 >    print('明年再會!')
 >```

[簡例]  輸入密碼,若密碼正確,顯示「密碼正確,歡迎光臨」;若密碼不正確,顯示「密碼錯誤,拒絕進入」。 (檔名: `password.py`)

 > [!example]- 程式碼:`password.py`
 >```python
 >pw = input('請輸入密碼：')
 >if (pw=="gotop168") :
 >    print('密碼正確，歡迎光臨')
 >else :
 >    print('密碼錯誤，拒絕進入') 
 >```

### 3. 巢狀選擇 if…else…

所謂 「巢狀選擇」是指 `if` 或 `else` 的敘述區段裡面，還有選擇結構，巢狀選擇結構就是將雙向選擇延伸成多向選擇。語法及流程圖如下：

![[assets/1. 結構化程式設計/IMG-20260718230555502.png|400]]

[簡例] 給予三個整數,使用巢狀選擇結構來找出三個整數中的最大數。  (檔名:`max.py`)

 > [!example]- 程式碼: `max.py`
 >```python
 >n1=34
 >n2=100
 >n3=-67
 >
 >print(f'三個整數分別為 {n1}, {n2}, {n3}')
 >if (n1>n2) :	            # 判斷 n1 是否大於 n2
 >     if(n1>n3) :           # 判斷 n1 是否大於 n3
 >         max=n1
 >     else :
 >         max=n3
 >else :				
 >     if(n2>n3) :		      # 判斷 n2 是否大於 n3
 >         max=n2
 >     else :
 >         max=n3 
 >print ()
 >print(f'比較結果: 最大數為 {max}')
 >```

### 4. 多向選擇 if…elif…else

當選擇的項目超過兩個，也可以使用「多向選擇」結構來處理。除第一個條件使用 **if** 判斷外，其他都使用**elif**，最後以 **else** 處理剩下的可能性。

![[assets/1. 結構化程式設計/IMG-20260718230733946.png]]

[簡例] (檔名:`movie.py`)
根據最低年齡制定電影分級,電影分級的規則如下:
1. 普遍級:0歲以上皆可欣賞。
2. 保護級:6歲(含)以上皆可欣賞。
3. 輔導級:12歲(含)以上皆可欣賞。
4. 限制級:18歲(含)以上皆可欣賞。
5. 預設為普遍級。

> [!example]- 程式碼: `movie.py`
>```python
>age=int(input('請輸入年齡(正整數)：'))
>rating = "普遍級"
>if age >= 18:
>     rating = "限制級"
>elif age >= 12:
>     rating = "輔導級"
>elif age >= 6: 
>     rating = "保護級"
>else:
>     rating = "普遍級"
>print(f'年齡{age}歲最高可看{rating}電影')
>```
