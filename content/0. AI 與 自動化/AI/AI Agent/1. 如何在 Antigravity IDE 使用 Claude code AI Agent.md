## Claude code 介紹

1. 性質有分 **Claude 訂閱制(Pro/Max)** 與 **API Key** 兩種方法
2. `Pro`或`Max`方案涵蓋在支援的 `IDE`中使用 `Claude Code`,包括 `VS Code`、`Cursor` 及其他`VS Code`分支,以及`JetBrains`系列`IDE`(如`IntelliJ`、`PyCharm`等),只需用終端機同一組 `Claude`帳號登入即可。 
3. `IDE` 中的使用量會計入與 `Claude` 和 `Claude Code` 共用的同一組用量上限,也就是說不會額外收費,是算在你原本訂閱的額度裡。

>**唯一要注意的例外:**  
如果你的系統上有設定`ANTHROPIC_API_KEY`環境變數,`Claude Code`會改用這組`API key`來驗證身份,而不是用你的訂閱方案,這樣就會產生額外的 API 用量費用,而不是走訂閱的額度。 

所以如果你發現`IDE`裡好像變成`API`計費而不是走訂閱額度,可以檢查一下系統環境變數裡是不是設了 `ANTHROPIC_API_KEY`,把它移除就會恢復用訂閱額度。

`JetBrains`的話需要從 `JetBrains Marketplace`安裝 `Claude Code`外掛,裝好後可能需要完全重啟`IDE`才會生效,`VS Code`系列則是安裝對應的擴充套件即可。


## 佈署與設定

1. 安裝 [Claude Code for VS Code](https://open-vsx.org/extension/Anthropic/claude-code)
2. 安裝後，開啟會出現以下
   ![[assets/1. 如何在 Antigravity IDE 使用 Claude code AI Agent/IMG-20260729195030572.png]]
3. 圖中的三個登入選項
   畫面顯示 **"How do you want to log in?"**,提供三種方式:
   - **Claude.ai Subscription**(橘色按鈕,建議選這個)
     - 說明文字寫著:使用你的 Claude Pro、Team 或 Enterprise 訂閱
     - 這是最簡單的方式,直接用你平常登入 claude.ai 的帳號密碼登入即可
     - 用量算在訂閱額度裡,不會額外收費(除非系統有設定 `ANTHROPIC_API_KEY`)
   - **Anthropic Console**
     - 說明是「透過 Console 帳號、以 API 用量計費」
     - 適合想用 API 按量計費、而非固定訂閱費用的人
   - **Bedrock, Foundry, or Vertex**
     - 適合企業已經在 AWS Bedrock / Azure AI Foundry / Google Vertex 上串接 API key 或第三方 provider 的情況
4. 建議設定步驟
   如果你是個人用戶、已經有 Claude Pro/Max 訂閱:
   - 點選 **「Claude.ai Subscription」**(橘色按鈕)
   - 會跳出瀏覽器視窗,用你的 Claude 帳號登入並授權
   - 授權完成後回到 Antigravity,Claude Code 面板就會啟用

5. 打開右側的 Claude code Agent
   按下`F1`鍵後輸入 `>Claude Code: Open in Sidebar`
   ![[assets/1. 如何在 Antigravity IDE 使用 Claude code AI Agent/IMG-20260729210930368.png]]

>簡單說: **只要點 `Claude.ai Subscription`用你的訂閱帳號登入,就能開始在 Antigravity 裡用 Claude Code 了。**
