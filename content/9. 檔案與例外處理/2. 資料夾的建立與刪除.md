## 前言

`Python`提供`os.path` 套件及`os`套件來進行檔案的操作。
本節將介紹使用 `os.path` 套件的 `isdir()` 與 `isfile()` 函式，分別來檢查指定的路徑是否為資料夾或檔案，以及使用`exists()`函式來檢查指定的檔案或資料夾是否存在。本節也將介紹使用`os`套件的`mkdir()` 函式來建立資料夾，及使用`rmdir()`函式來刪除資料夾。

## isdir()、isfile() 函式

`os.path` 套件的`isdir()`與`isfile()`函式,分別用來檢查指定的資料夾路徑名稱與檔案路徑名稱是否存在,語法如下:

```python
os.path.isdir(資料夾路徑名稱)

os.path.isfile(檔案路徑名稱)
```

1. 資料夾路徑名稱與檔案路徑名稱,皆屬字串型別。
2. 若指定的路徑名稱存在,則傳回值為 `True`;若不存在,則傳回值為`False`。
3. 在使用`isdir()`或`isfile()`函式前須使用`import`指令匯入`os.path`套件名稱或`os`套件名稱。

[簡例] (檔名:`path01.py`)

使用`isdir()`函式檢查 c:磁碟機是否存在有『c:/data/』資料夾,及使用`isfile()`函式檢查『c:/Windows/system.ini』檔案是否存在。

[結果]

```yaml
c:/data/ 資料夾路徑不存在                                            
c:/Windows/system.ini 路徑為檔案
```

> [!example]- 程式碼:`path01.py`
> ```python
> import os
> pName = 'c:/data/'
> # 判斷指定的路徑是否存在且**是一個資料夾。如果是印出: c:/data/ 路徑為資料夾，否則印出 c:/data/ 資料夾路徑不存在
> if os.path.isdir(pName):
>     print(f'{pName} 路徑為資料夾')
> else:
>     print(f'{pName} 資料夾路徑不存在')
> fName = 'c:/Windows/system.ini'
> # 判斷指定的路徑是否存在且是一個檔案。如果是印出: c:/Windows/system.ini 路徑為檔案，否則印出 c:/Windows/system.ini 檔案路徑不存在
> if os.path.isfile(fName):
>     print(f'{fName} 路徑為檔案')
> else:
>     print(f'{fName} 檔案路徑不存在')
> ```

>說明
>1. 若`c:`磁碟機已事先建立『c:/data/』資料夾,則結果會如下:
>  `c:/data/` 路徑為資料夾
>2. 第`1`行:用`import`匯入`os`套件名稱。(`os`套件包含了`os.path`套件)
>3. 第`2`行:將`'c:/data/'`字串指定給 `pName` 變數。
>4. 第`4`行:檢查`'c:/data'`資料夾路徑是否存在。若存在傳回`True`,則執行第`5`行;若不存在傳回`False`,則執行第`7`行。
>5. 第`8`,`10`行:`'c:/Windows/system.ini'`為`Windows`系統必備的檔案,該檔案路徑必然是存在的,故會傳回`True`,執行第`11`行

## exists() 函式

`os.path`套件的`exists()`函式是用來指定的檔案或資料夾路徑名稱是否存在,可同時取代`isdir()`及`isfile()`函式。語法如下:

```python
os.path.exists(路徑名稱)
```

1. 路徑名稱:為檔案或資料夾的路徑名稱,屬字串型別。
2. 若指定的檔案或資料夾路徑存在,則傳回值為`True`;若不存在,則傳回`False`。
3. 在使用`exists()`函式前須用`import`匯入`os.path`套件名稱或 `os`套件名稱。

[簡例] 使用`exists()`函式來檢查 `c:`磁碟是否存在有『c:/data/』資料夾,也使用`exists()` 函式來檢查 『c:/Windows/system.ini』檔案是否存在。 (檔名:`path02.py`)

[結果]

```yaml
c:/data/ 資料夾路徑不存在
c:/Windows/system.ini 路徑為檔案
```

> [!example]- 程式碼:`path02.py`
> ```python
> import os
> pName = 'c:/data/'
> if os.path.exists(pName):
>     print(f'{pName} 路徑為資料夾')
> else:
>     print(f'{pName} 資料夾路徑不存在')
>    
> fName = 'c:/Windows/system.ini'
> if os.path.exists(fName):
>     print(f'{fName} 路徑為檔案')
> else:
>     print(f'{fName} 檔案路徑不存在') 
> ```

## mkdir() 函式

`os`套件的`mkdir()`函式是用來建立資料夾(或稱目錄)的路徑名稱,語法如下:

```python
os.mkdir(路徑名稱)
```

在指定的路徑中建立資料夾,若路徑中的上一層目錄不存在,會出現錯誤。
若資料夾已存在,也會出現錯誤訊息,所以常和`os.path.exists()`函式或`os.path.isdir()`搭配使用。

[簡例] 在`c:`磁碟機建立『c:/data/』資料夾。 (檔名:`path03.py`)
[結果]

```yaml
c:/data/ 路徑不存在
c:/data  資料夾建立成功
```

> [!example]- 程式碼:`path03.py`
> ```python
> import os
> pName = 'c:/data/'
> if os.path.exists(pName):
>     print(f'{pName} 路徑已存在,不必再建立')
> else:
>     print(f'{pName} 路徑不存在')
>     os.mkdir(pName)
>     print(f'{pName} 資料夾建立成功')
> ```

## rmdir() 函式

`os`套件的`rmdir()`函式是用來刪除已存在的空資料夾(或稱目錄),語法如下:

```python
os.rmdir(路徑名稱)
```

1. 使用本函式須和 `os.path.exists()`函式搭配,要先確定要刪除的資料夾是否存在,才能進一步進行刪除動作。

2. 若要刪除的資料夾不存在,或是其中有檔案時,而直接使用`rmdir()`函式時會
   出現錯誤訊息。

[簡例] 在`c:`磁碟機建立『c:/data/』資料夾。 (檔名:`path04.py`)

[結果]

```yaml
c:/data/ 路徑目前存在
c:/data/ 路徑已刪除
```

> [!example]- 程式碼:`path04.py`
> ```python
> import os
> pName = 'c:/data/'
> if os.path.exists(pName):
>     print(f'{pName} 路徑目前存在')
>     os.rmdir(pName)
>     print(f'{pName} 路徑已刪除')
> else:
>     print(f'{pName} 路徑不存在')
> ```
